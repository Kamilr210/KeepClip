KeepClip Update - v2.4.0

- Added CS2 demo links. You can now attach a .dem file, including demos downloaded from FACEIT, to a clip. KeepClip saves its location without copying it, so the demo stays in your CS2 folder and remains available in the game. You can replace the link, remove it, or show the file in Explorer.
- Fixed clipping failures with 10-bit recordings. KeepClip now uses a compatible H.264 output format and automatically switches to CPU encoding if the NVIDIA encoder fails. Failed cuts are cleaned up, empty output is rejected, and error messages include the original cause.
- Added options to hide clips already organized into folders from the home page. You can apply this to all folders or choose individual ones. The clips remain available in their folders and in favorites.
- Added an option to show favorites after the four newest clips in the default library view.
- Reorganized Settings into sections, added settings search and a Discord support shortcut, and improved the storage usage display.
- Fixed a problem where a clip could disappear from the library even though moving its file to the Recycle Bin failed. Replay saving also avoids overwriting an existing recording.
- Improved Google Drive login, token refresh, disconnecting and switching accounts. Long cloud filenames now keep their file extensions, and invalid metadata is handled more safely.
- Fixed incomplete transcript updates after a save error and thumbnail generation stopping when one clip was missing or unreadable. Cancelled previews no longer remove the output of a newer task.
- Improved character encoding in downloaded .txt transcripts and handling of unavailable or previously failed speech recognition models.
- Fixed number keys in replay shortcuts, including Alt+1 and Ctrl+0. Improved recovery after replay recording errors and added clearer startup diagnostics.
- Improved search input validation and protection around file paths, imported filenames and desktop integration. Database migrations preserve existing library data, and the installer includes verified dependency notices and FFmpeg sources.
- Expanded automated regression tests, including actual FFmpeg encoding of synthetic recordings, GPU failure recovery, file size limits, demo links, cloud operations and library data integrity.

Download **KeepClip-Setup.exe** below to install or update. **KeepClip-FFmpeg-Source.zip** contains the corresponding FFmpeg sources and build materials; it is not required to run the app.
