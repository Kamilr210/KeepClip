# Changelog

Все заметные изменения в **KeepClip** фиксируются в этом файле, начиная с версии **2.5.0**.

## [2.5.1] — 2026-11-23

### Плеер в стиле YouTube
- Полностью переработан встроенный видеоплеер (`PlayerView`): панель управления перенесена поверх видео с мягким тёмным градиентом и автоскрытием при бездействии курсора во время воспроизведения.
- Добавлены режимы увеличения видео: **широкий / кинотеатр** (`T`) и **полноэкранный режим** (`F` или двойной клик по видео, `Esc` для выхода) с наложенным заголовком и скрытием системных кнопок окна.
- Заменены эмодзи-кнопки на чёткие векторные иконки (`Path`), добавлен предпросмотр времени при наведении на полосу перемотки, всплывающее меню скорости (`0.25×`–`2×`), индикатор активных субтитров `CC`, центральный индикатор действий (пауза/пуск/перемотка) и подсветка текущего сегмента транскрипции.
- Расширены горячие клавиши плеера: `Space`/`K` (пауза/пуск), `F` (полный экран), `T` (широкий режим), `M` (звук), `C` (субтитры), `J`/`L`/`←`/`→` (-5с/+5с), `↑`/`↓` (громкость).

### Обрезка и остальные меню приложения
- Переработано окно обрезки (`CutWindow`): добавлен плеер предпросмотра с наложенным управлением, визуальная полоса выделенного фрагмента с бегунком воспроизведения, кнопки быстрого задания начала/конца «Отсюда» / «Досюда», перетаскивание окна за шапку и горячие клавиши (`Space`, `←`/`→`, `Esc`).
- Добавлены единые тёмные стили в `Themes/Theme.xaml` для `CheckBox`, `Slider` (`YouTubeSlider`), `ProgressBar`, `Separator` (в контекстных меню), `ToolTip`, кнопок заголовка окна (`TitlebarButton`, `TitlebarCloseButton`), кнопок на карточках (`CardOverlayButton`) и hover-подсветки карточек (`InteractiveCardBorder`).
- Проработаны оверлей мгновенного повтора (`ReplayView` — карточные переключатели, бейдж статуса, закрытие кликом по фону) и модальные диалоги (`PromptDialog`, `ConfigFolderDialog`, `OnboardingWindow` — тени, перетаскивание за шапку, индикатор шагов обучения и навигация с клавиатуры).
- Убран дублирующий набор кнопок заголовка в `MainWindow` и добавлено обновление иконки разворачивания окна (`☐` / `❐`).

## [2.5.0] — 2026-11-23

### Архитектура и перевод на WPF
- Приложение переведено с WinForms + WebView2 + ASP.NET Core на нативное **WPF (.NET 10)** приложение.
- Веб-интерфейс (`frontend/`), локальный веб-сервер (`Endpoints/`, `Program.cs`, `PrivateApi*`, `Heartbeat.cs`) и `Microsoft.Web.WebView2` удалены.
- Локализация (`pl`, `en`, `uk`, `ru`), темы оформления (`purple` / `green`), диалоги, плеер (`MediaElement`) и система уведомлений (`ReplayToast`) перенесены на C# и XAML.
- Для потокового воспроизведения клипов из Google Drive добавлен лёгкий loopback-прокси `CloudVideoProxy`.

### Исправления
- Исправлены белые выпадающие списки (`ComboBox`, `ComboBoxItem`) и белые контекстные меню (`ContextMenu`, `MenuItem`, `ToolTip`) — добавлены полноценные тёмные шаблоны в `Themes/Theme.xaml`.
- Исправлены отсутствующие ключи переводов в окне обучения (`OnboardingWindow` теперь использует `onboarding.steps.*` и `onboarding.back`), диалоге выбора папки (`ConfigFolderDialog`), диалоге создания папки (`folders.newFolderLabel` / `folders.addBtn`), меню папок в плеере (`folders.noFolders`) и контекстном меню карточек (`clipMenu.*`).
- Исправлена вёрстка верхней панели в `OnboardingWindow` (кнопка «Пропустить обучение» больше не растягивается на всю ширину).
- Добавлен текст-подсказка (watermark/placeholder) для полей поиска в главном окне и настройках.
- Добавлено автоматическое обновление карточек при фоновой генерации миниатюр (`ThumbnailWorker`) и заглушка превью для клипов без миниатюры.
- Исправлено обновление текстов выпадающих списков сортировки и тем при смене языка в настройках.
- Исправлено отображение текста в выпадающих списках (`ComboBox` больше не показывает `ComboChoice { ... }` / `AudioChoice { ... }`).
- Очищены HTML-теги (`<b>`, `<br>`, `<code>`) из строк локализации в `Loc.T`.
- Окна `PlayerWindow`, `LogsWindow` и `ResourcesWindow` переведены на кастомную тёмную шапку (`WindowStyle="None"` + `WindowChrome`) без белой системной полоски.
- Добавлен тёмный стиль полос прокрутки (`ScrollBar`) и плейсхолдер для поля пути демо CS2.
- Логотип `KEEPCLIP` поднят на самый верх боковой панели, убран дублирующий мелкий заголовок сверху.
- Выровнена верхняя панель поиска и фильтров на главной странице (`Height="38"` для всех элементов).
- «Мгновенный повтор» (`ReplayView`) и плеер (`PlayerView`) встроены прямо внутрь главного окна вместо отдельных окон.
- Страница плеера полностью перекрывает рабочую область (без торчащей шапки сайдбара), добавлена перемотка в стиле YouTube под видео и горизонтальная панель всех действий без прокрутки.
- Поток транскрибации переведён на пониженный приоритет (`ThreadPriority.BelowNormal`), чтобы интерфейс не зависал во время работы Whisper.
- Исправлены пути проектов в корневом файле решения `KeepClip.slnx`.
