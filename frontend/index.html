Chmura

        Przechowuj klipy na własnym Google Drive i odtwarzaj je strumieniowo.
      


      

        

        Sprawdzam stan połączenia…
      


      
      

        

          

            
          

          
Podłącz własny Google Drive

          

            KeepClip nie ma własnego serwera — używasz swojego konta Google Drive.
            Aby to zadziałało, jednorazowo utwórz darmowego klienta OAuth i wgraj go do aplikacji.
          

        

        
    
          
  1. Wejdź na Google Cloud Console i utwórz projekt (darmowy).
    2. 
          
  2. Włącz Google Drive API (APIs & Services → Library).
    3. 
          
  3. W OAuth consent screen wybierz „External", dodaj siebie jako Test user.
    4. 
          
  4. W Credentials utwórz OAuth client ID typu Desktop app i pobierz plik JSON.
    5. 
          
  5. Zmień jego nazwę na google_client.json i wrzuć do folderu data w katalogu KeepClip.
    6. 
        

        

          
          Po wgraniu pliku kliknij „Sprawdź ponownie".
        

      


      
      

        

          

            
          

          
Połącz z Google Drive

          

            Klient OAuth jest gotowy. Kliknij poniżej i zaloguj się na swoje konto Google,
            aby KeepClip mógł zapisywać klipy w folderze KeepClip na Twoim Dysku.
          

        

        

          
        

        

          KeepClip prosi tylko o dostęp do plików, które sam tworzy (zakres drive.file) —
          nie widzi reszty Twojego Dysku. Token logowania trzymany jest w Menedżerze poświadczeń Windows.
        

      


      
      

        

          
          

            

            

          

          ● Połączono
          
        

        

          

          

        

        

        

          Wyślij klip do chmury z menu „⋯" na kafelku klipu albo z okna odtwarzania.
          Cały folder wyślesz przyciskiem w jego nagłówku. Klipy w chmurze odtwarzają się strumieniowo.
        

      

    

  






  

    
Usuń klip?

    

    
Plik zostanie przeniesiony do Kosza Windows — w razie pomyłki możesz go odzyskać.

    

      
      
    

  






  

    
Wskaż folder z klipami

    

      Aplikacja przeszuka ten folder i wszystkie pod-foldery w poszukiwaniu plików wideo.
      Typowa lokalizacja klipów NVIDIA ShadowPlay to C:\Users\<ty>\Videos\NVIDIA.
